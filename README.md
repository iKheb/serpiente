# Serpiente Neón

Juego clásico de la serpiente con estética neón, en un único archivo HTML sin dependencias.

## Cómo jugar

Abre `index.html` en cualquier navegador moderno. No requiere instalación ni servidor.

## Controles

| Acción | Teclado | Móvil |
| --- | --- | --- |
| Mover | Flechas o `W` `A` `S` `D` | Deslizar el dedo |
| Pausar / reanudar | `Espacio` | — |
| Reiniciar tras perder | `Espacio` | Tocar la pantalla |

## Reglas

- Come las bolas magenta para sumar puntos; cada una acelera un poco la serpiente.
- Pierdes si chocas con una pared o con tu propio cuerpo.
- El récord se guarda en el navegador (`localStorage`).
